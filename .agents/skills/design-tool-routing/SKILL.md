# Gymkana design tool routing

Authority: `PRODUCT_TRUTH + OWNER + GYMKANA_VISUAL_CONTRACT > EXTERNAL_REFERENCE_OR_TOOL`.

Use only when a material visual change is actually required. Do not spend release/freeze time on design ceremony for unaffected surfaces.

Flow when applicable:
`PRODUCT_TRUTH -> REAL_SHIPPED_REFERENCE -> DISTINCT_DIRECTIONS -> SELECTED_VISUAL_TARGET -> IMPLEMENTATION -> ANTI_SLOP_PRECHECK -> EXACT_HEAD_PIXEL_QA -> ART_DIRECTOR_POST -> OWNER_QA`.

## References
Mobbin or equivalent may inform mechanics, hierarchy, pacing, state treatment and discoverability.

`REFERENCE != STYLE_AUTHORITY`.

Preserve the correspondence/keepsake identity, narrative pacing, surprise/spoiler logic and performance constraints; do not turn the experience into a generic app template.

## Exploration
Use Product Design or equivalent only while a material composition/interaction decision is unresolved.

`THREE_RECOLORS != THREE_DIRECTIONS`.

## Craft precheck
Impeccable or equivalent may be used only as a writer-side anti-slop/craft precheck. Relevant lenses include `audit`, `layout`, `typeset`, `distill`, `harden`, `polish`.

`AI_SLOP_DETECTOR != DESIGN_AUTHORITY`.

If unavailable, use `.agents/skills/art-direction/SKILL.md` directly.

## Provider routing
- ChatGPT/Work Art Director may use connected Mobbin/Product Design and persists useful findings durably.
- Gemini/Antigravity consumes repo skills and durable research; no invented references.
- Codex consumes canonical `.agents/skills/*` contracts.

`MCP_AVAILABLE != MCP_JUSTIFIED`; use connectors only for live data/actions that change the mission.

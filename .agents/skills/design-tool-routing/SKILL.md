# Gymkana design tool routing

Authority: `PRODUCT_TRUTH + OWNER + GYMKANA_VISUAL_CONTRACT > EXTERNAL_REFERENCE_OR_TOOL`.

Use only when a material visual change is actually required. Do not spend release/freeze time on design ceremony for unaffected surfaces.

Flow when applicable:
`PRODUCT_TRUTH -> MULTI_SOURCE_SHIPPED_RESEARCH -> DISTINCT_DIRECTIONS -> SELECTED_VISUAL_TARGET -> FIGMA/PROTOTYPE_WHEN_USEFUL -> IMPLEMENTATION -> ANTI_SLOP_PRECHECK -> EXACT_HEAD_PIXEL_QA -> ART_DIRECTOR_POST -> OWNER_QA`.

## References
`ONE_REFERENCE_LIBRARY != RESEARCH_STRATEGY`.

For a material visual decision, normally triangulate about 5–8 relevant sources when the category supports it: 3+ shipped products/experiences, official platform/design guidance where applicable, and independent UX/user evidence when useful. Mobbin, Refero, Page Flows, UXArchive or equivalent are optional accelerators; if a source is paid/blocked, continue with public shipped evidence instead of stopping at 1–2 sites.

Rules:
- `REFERENCE != STYLE_AUTHORITY`;
- `SOURCE_DIVERSITY > SOURCE_COUNT_THEATRE`;
- never invent unavailable evidence;
- preserve the correspondence/keepsake identity, narrative pacing, surprise/spoiler logic and performance constraints; do not turn the experience into a generic app template.

## Exploration
Use Product Design or equivalent only while a material composition/interaction decision is unresolved.

`THREE_RECOLORS != THREE_DIRECTIONS`.

## Figma / editable hand-off
After a direction is selected, Figma may materialize screens/components/prototypes when that reduces implementation ambiguity.

`FIGMA_ARTIFACT != PRODUCT_TRUTH`.

Do not use Figma as process theatre for small/frozen-scope fixes.

## Craft precheck
Impeccable or equivalent may be used only as a writer-side anti-slop/craft precheck. Relevant lenses include `audit`, `layout`, `typeset`, `distill`, `harden`, `polish`.

`AI_SLOP_DETECTOR != DESIGN_AUTHORITY`.

If unavailable, use `.agents/skills/art-direction/SKILL.md` directly.

## Provider routing
- ChatGPT/Work Art Director may perform multi-source live research, use Product Design when direction is unresolved, and use connected Figma after direction selection; persist useful findings durably.
- Gemini/Antigravity consumes repo skills and durable research; no invented references.
- Codex consumes canonical `.agents/skills/*` contracts.

`MCP_AVAILABLE != MCP_JUSTIFIED`; use connectors only for live data/actions that change the mission.

# Frontend runtime quality

`MEASURE_BEFORE_OPTIMIZE` · `RUNTIME_EVIDENCE > SOURCE_CONFIDENCE` · `ACCESSIBILITY_IS_BEHAVIOR`.

Evita waterfalls; controla bundle/carga condicional; conserva server/client boundaries; optimiza renders solo con evidencia; estados loading/error/empty honestos; focus/targets/labels claros; mide performance cuando se afirma mejora.

Herramientas: `DEVTOOLS_DIAGNOSES` · `PLAYWRIGHT_REPEATS` · `LIGHTHOUSE_MEASURES_PAGE_HEALTH`.

Para UI material: fuente + runtime + estado adversarial. Para performance: baseline -> cambio -> medición comparable.

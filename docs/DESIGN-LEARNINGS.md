# Gymkana — Design Learnings

Registro ligero de aprendizajes visuales. Solo se actualiza cuando existe una lección real; no crear burocracia para este proyecto temporal.

## Principios globales heredados
- benchmark/referencia adoptada debe traducirse a una decisión observable;
- distintividad también debe pasar category-fit/context-fit;
- funciones críticas deben ser descubribles cuando se necesitan;
- media/motion deben corresponder al propósito narrativo o interactivo;
- CI/JSX/CSS no sustituyen una vista renderizada cuando la apariencia importa.

## L-G01 — La sorpresa manda sobre el design-system
**Regla:** no añadir complejidad visual, 3D, navegación o patrones solo para “hacerlo más premium”. Cada decisión debe mejorar anticipación, intimidad, revelación o claridad de la ruta.
**Clasificación:** PROJECT.

## L-G02 — Correspondencia no significa plantilla romántica genérica
**Regla:** el lenguaje papel/carta/sello/pétalo solo funciona si apoya el relato concreto. Evitar convertirlo en una landing rosa estándar o un conjunto de cards románticas intercambiables.
**Clasificación:** PROJECT/CATEGORY.

## L-G03 — Pacing es parte de la interfaz
**Regla:** en una sorpresa, el orden, espera, reveal y transición son información. El motion y la composición deben proteger ese ritmo en vez de decorar cada pantalla.
**Clasificación:** PROJECT.
